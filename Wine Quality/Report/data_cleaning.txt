Data Collection & Cleaning

Data Collection
The Wine Quality dataset was imported and stored as a raw CSV file (`wine_quality_raw.csv`) 
to preserve the original data and ensure reproducibility throughout the project.


Initial Data Inspection
A preliminary inspection was performed to understand the dataset structure and quality.

- Initial dataset shape: 6,497 rows × 13 columns
- Displayed sample records using `head()` to verify successful import.
- Reviewed column names and data types using `info()`.


Missing Value Analysis

The dataset was checked for missing values using:
```python
df.isnull().sum() 
```
Finding: No missing values were detected in any of the features.


Duplicate Value Analysis

The dataset was checked for duplicate records using:
```python
df.duplicated().sum()
```
Finding: 1,177 duplicate rows were identified.

To improve data quality and prevent biased analysis and model performance, duplicate records were removed.
- Rows before duplicate removal: 6,497
- Duplicate rows removed: 1,177
- Rows after duplicate removal: 5,320


Outcome
The dataset is free of missing values and was successfully cleaned by removing duplicate records. 
Preliminary statistical analysis identified several features with potential outliers and varying degrees of skewness, 
providing a strong foundation for the next stage of Exploratory Data Analysis (EDA), visualization, feature engineering, and predictive modeling.
